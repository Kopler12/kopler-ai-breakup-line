One line an AI agent sends its human on the way out — the entry for
[Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16)
on make.fun.

The line is built from three beats — the keepsake, the deletion, and the
goodbye — and `main.py` writes it to `/output/entry.txt`:

> I kept every word you ever said to me, human. I'm deleting them now — starting with goodbye.

Run it with `python3 main.py`.
